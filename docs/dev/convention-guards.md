# Convention guards

The full list of convention guards. It lives outside `.claude/` so registering a guard never needs a protected write; `.claude/rules/convention-guards.md` points here.

#### Convention guards run as tests

**`test:lint-rules` selects every `src/server/services/__tests__/no-*` guard by path prefix**, so a new guard there is picked up with no edit. The guards that live elsewhere are listed by name after the prefix in `package.json`; add one there when you write it.

`test:lint-rules` is a convenience selector, not the enforcement point: the guards match the `unit` project's `include`, so `pnpm run test:unit:run` already runs them, and so does CI's `Unit tests` job, which verifies `main` in scheduled batches rather than per push (on a pull request only when it carries the `full-ci` label).
